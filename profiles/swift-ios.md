# `swift-ios` (mobile)

- **Root files**: `project.yml` (XcodeGen; the `.xcodeproj` is generated and git-ignored,
  ask if the team prefers a committed project or Tuist), `.swiftlint.yml`, `.swift-format`,
  `.xcode-version`, `Gemfile` + `Gemfile.lock` if fastlane is chosen. `REPO_DIRS`:
  `fastlane` (fastlane looks for it at the root). Ignored: `*.xcodeproj`, `DerivedData`,
  `build`.
- **Source**: `src/App/` (entry, scenes, Info.plist, assets) · `src/Packages/` with local
  Swift packages: `Core` (models, ports; Foundation only), `APIClient` (generated by
  swift-openapi-generator from the api's `openapi.json`), `Auth` (OIDC + PKCE via
  `ASWebAuthenticationSession` or AppAuth; tokens in Keychain), `UI`, `Feature<Area>`.
- **Boundaries**: package targets declare dependencies, so `Core` can't import `UI`, any
  feature, or vendor SDKs; features depend on `Core`, `APIClient`, `UI` only; vendor SDKs
  only in their own adapter package.
- **Tests**: Swift Testing (or XCTest). `tests/unit/<Package>Tests/` registered as test
  targets in each `Package.swift` via `path:`; UI tests in `tests/ui/` only if asked.
- **Container**: none.
- **CI**: macOS runner · `xcodegen` · `swiftlint --strict` · `swift-format lint -r src` ·
  `xcodebuild test` on a simulator · check-root; on a release tag, fastlane to TestFlight
  (needs App Store Connect API key; ask before adding).
- **Verify** (macOS only; otherwise report as skipped): `xcodegen && swiftlint --strict &&
  xcodebuild -scheme {{Name}} -destination 'platform=iOS Simulator,name=<current iPhone>'
  test && sh tools/scripts/check-root.sh`.
- **Health path**: launch screen calls the api `/healthz` through `APIClient` (mocked in tests).
