# Changelog

## 1.0.0 — 2026-10-05

First release as Stackwright (previously the `polyrepo-boilerplate` skill).

- Stack-neutral core: layout rules, six-round interview, plan confirmation, Add mode,
  verify and git phases.
- Topologies: polyrepo, monorepo, custom.
- 14 profiles. Proven by the 3DP scaffold (2026-10-05): `ts-nest`, `react-vite`,
  `postgres-drizzle`, `compose-northflank`. Written: `ts-fastify`, `python-fastapi`,
  `dotnet`, `nextjs`, `expo-react-native`, `swift-ios`, `postgres-sql-only`,
  `orm-migrations`, `compose-terraform`, `bring-your-own`.
- Check-root templates in Node, Python and POSIX shell, tested against fixtures.
- Self-checks (`tools/test.sh`) and CI that packages the skill as a zip.
